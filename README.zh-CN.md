# Eidos Lite 的 Flexoki 主题

Flexoki 为 Eidos Lite 带来暖纸、深墨和低饱和度的青色点缀。编辑器、表格、侧栏和控件会随应用的外观设置切换浅色或深色配色。

## 安装

1. 在 Eidos Lite 打开 **插件 → 插件市场**，搜索 **Flexoki**。
2. 安装后，在 **插件 → 已安装** 中选择 Flexoki。主题会应用到所有空间。
3. 在 **设置 → 外观** 中选择浅色、深色或跟随系统。

需要 Eidos Lite 0.29.0 或更新版本，支持插件 API 3.7.0。主题只包含样式，无需任何权限。
